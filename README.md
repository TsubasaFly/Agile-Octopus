# Octopus Agile 2026 用电与价格匹配分析

本目录包含你的 Octopus Energy Agile 2026 年度用电数据拉取程序、全景分析仪表盘及自动化更新流程。

> 📖 **更新日志 (Changelog)**：详细的版本迭代、功能升级与数据同步记录请查阅 [CHANGELOG.md](file:///F:/Octopus%20Analysis/CHANGELOG.md)。

---

## 文件列表与核心功能

1. **`octopus_agile_usage_2026.csv`**
   * **数据周期**：2026-01-01 至最新（当前覆盖至 2026-11-18，共 15,446 个半小时时段）
   * **数据内容**：每半小时的消耗电量、Agile 含税单价、纯电费支出、是否为晚高峰（16:00-19:00）、是否为负电价时段等。

2. **`dashboard.html` / `public/index.html`**
   * **全景交互式仪表盘**：
     * **月度使用与账单全景视图 (Monthly Overview)**：包含 11 个月的走势图、月度总和卡片、对比明细表（含每日固定费 Standing Charge、全包电费及对比 Ofgem SVT 限价节省）。
     * **价格区间负荷分布**（7 档价格区间负荷柱形图）。
     * **每日用电与价格走势图**及 **48 个半小时精细时段下钻图**。
     * **24 小时分时画像与峰谷特征图**。

3. **`generate_dashboard.py`**
   * 基于本地 `octopus_agile_usage_2026.csv` 快速重新计算并生成 `dashboard.html`。

4. **`download_and_analyze.py`**
   * 自动加载同目录下 `API key.txt`，从 Octopus REST API 拉取 2026 至今的全量用电与电价数据并重新生成 CSV。

5. **`build_dashboard.py`**
   * 自包含的全流程构建脚本，直接通过 API 拉取数据并生成 `public/index.html`，由 GitHub Actions 自动化调度并部署至 GitHub Pages。

6. **`update_all.py` / `run_update.bat`**
   * 一键全自动更新流水线：拉取最新数据 -> 更新 CSV -> 重新渲染 `dashboard.html` 与 `public/index.html` -> 记录更新日志至 `update.log`。
